# ESP32 Light Control 💡📱

Учебный проект для локального управления освещением (светодиодами) по Wi-Fi с помощью микроконтроллера ESP32 и кастомного Android-приложения. Проект демонстрирует принципы построения IoT-устройств, работу с ШИМ-сигналом (PWM) и создание собственного HTTP-сервера на базе ESP32, работающего в режиме точки доступа без необходимости подключения к глобальной сети Интернет.

## Возможности
*   **Автономная сеть:** ESP32 создает собственную Wi-Fi точку доступа.
*   **Управление питанием:** Включение и выключение светодиода кнопками из приложения.
*   **Регулировка яркости:** Плавное изменение яркости с помощью ползунка (SeekBar) за счет ШИМ-сигнала.
*   **Мониторинг статуса:** Приложение в реальном времени отображает статус подключения к плате.
*   **Настройки IP:** Возможность ручного изменения IP-адреса платы в настройках приложения.

## Компоненты для сборки

Для сборки физической схемы использовались следующие компоненты:
1.  **Микроконтроллер:** ESP32-DevKitC V2 (38-pin)
2.  **Макетная плата:** Беспаечная (Breadboard) на 830 точек
3.  **Светодиод:** 5 мм (синего свечения)
4.  **Резистор:** 220 Ом (для ограничения тока и защиты светодиода/порта)
5.  **Провода:** Соединительные Dupont-перемычки (папа-папа)
6.  **Кабель:** Micro-USB с поддержкой передачи данных

## Исходный код прошивки (Скетч Arduino IDE)

Код настраивает плату как точку доступа и поднимает веб-сервер на 80 порту для обработки GET-запросов от смартфона.

```cpp
#include <WiFi.h>
#include <WebServer.h>

WebServer server(80);

const int ledPin = 5;       // Пин G5, к которому подключена длинная ножка светодиода
const int freq = 5000;      // Частота ШИМ (5 кГц)
const int resolution = 8;   // Разрешение 8 бит (диапазон яркости от 0 до 255)

void setup() {
  Serial.begin(115200);
  
  // Настройка пина для плавной регулировки яркости
  ledcAttach(ledPin, freq, resolution);
  ledcWrite(ledPin, 0);

  // Создаем точку доступа
  WiFi.softAP("ESP32_Polyakov", "12345678");
  
  Serial.print("Wi-Fi точка доступа запущена. IP адрес: ");
  Serial.println(WiFi.softAPIP());

  // 1. Проверка статуса
  server.on("/status", []() {
    server.send(200, "text/plain", "OK");
  });

  // 2. Команда полного включения
  server.on("/led_on", []() {
    ledcWrite(ledPin, 255);
    server.send(200, "text/plain", "ON");
  });

  // 3. Команда выключения
  server.on("/led_off", []() {
    ledcWrite(ledPin, 0);
    server.send(200, "text/plain", "OFF");
  });

  // 4. Команда изменения яркости с ползунка
  server.on("/brightness", []() {
    if (server.hasArg("val")) {
      int brightness = server.arg("val").toInt();
      ledcWrite(ledPin, brightness);
    }
    server.send(200, "text/plain", "OK");
  });

  // Запуск веб-сервера
  server.begin();
  Serial.println("HTTP сервер запущен и ждет команды!");
}

void loop() {
  // Постоянно слушаем входящие HTTP-запросы от смартфона
  server.handleClient(); 
}
```

## Установка и запуск

1. Соберите схему на макетной плате, как показано на изображениях выше.
2. Прошейте ESP32 с помощью Arduino IDE (убедитесь, что установлен драйвер CP210x и выбрана плата ESP32 Dev Module).
3. Установите скомпилированное Android-приложение на ваш смартфон.
4. В настройках смартфона отключите мобильный интернет и подключитесь к Wi-Fi сети `ESP32_Polyakov` (пароль: `12345678`).
5. Откройте приложение - статус должен измениться на «Подключено», после чего можно управлять светом.
